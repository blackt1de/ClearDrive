# Release Notes for V2.0.0 Beta

## Features & Fixes:
- Generic trim filtering for Mercedes, BMW, Ford, Audi (fixes CarsXE model mismatches).
- Mercedes-AMG normalization with NHTSA VIN decode fallback.
- Improved turbo detection (2.0T/3.0T patterns).
- Skip part/detail images.
- iOS: fix stale vehicle data, add live OBD fuel level & odometer, show "N/A" for unsupported PIDs, embed legal docs, better transmission selection.
- Backend: enhanced vehicle lookup and improved data validation.
